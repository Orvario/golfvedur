# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Icelandic golfers checking course weather before heading out (tee times, wind, rain).

## Product Purpose

Golfveður shows hourly and multi-day weather for golf courses across Iceland so players can pick when and where to play.

## Positioning

Course-first weather: every forecast is tied to a real Icelandic golf course (location, club, contacts), not a generic city forecast.

## Capabilities

- Browse and search Icelandic golf courses
- Favourite course (localStorage)
- Current + hourly weather with swipeable hour selection
- 5-day forecast with list and graph views
- Share weather snapshot
- Course info (address, phone, email, web, coordinates)

## Constraints

- Icelandic UI copy
- Belgingur / yr.no symbol and forecast data model
- Preserve all existing features; visual redesign only
- Mobile-first PWA-style web app

## Brand Commitments

- Product name: Golfveður
- Visual direction (2026 redesign): dark glass weather UI matching the approved reference mock — deep navy ground, blue gradient weather plates, soft rounded cards, metric row, glowing hourly selection

## Voice

Direct Icelandic. Functional labels (Núna, Næstu 5 dagar, Deila). No marketing fluff.

## Accessibility

Touch-first. Preserve contrast on dark surfaces; keep keyboard-focusable controls.
